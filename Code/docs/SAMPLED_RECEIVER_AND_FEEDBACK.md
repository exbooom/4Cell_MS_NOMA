# 有限采样接收、测距与估计几何反馈

阶段7实现说明，2026-11-01。已完成97项检查和五个完整场景验收；确切结果与状态以STAGE7_VERIFICATION.json和PROGRESS阶段7为准。

## 工程步长的约定

用户已明确允许自行设置、试验数值步长。默认保留已通过证书的投影/回溯方法，将初始内外步长同时乘0.01、1、100作为敏感性实验。它们作用于已缩放的对偶坐标，不能直接解释为作者未缩放b1/b2/b3。回溯后的实际接受步长、工作量、原始可行性、相对可听性、KKT和对偶间隙分别保存；不以“相邻价格变化很小”代替收敛验收。

## 波形、信道与有限观测

- K个同步BS，每站M个矩形BPSK定位分量和N个矩形QPSK通信分量；所有通信载波均发送，功率沿用优化输入；无CP、单路径、无多普勒。
- 采样率 `Fs=oversampling*B`，每定位码片采样数 `(M+1)*oversampling`，与整数numerology严格一致。默认4倍采样、1023码片；这是显式工程选择，不是作者接收机参数。
- 载波频率围绕 `(N+1)*deltaFc/2` 居中。N+1为奇数时，通信IFFT后补全半bin的连续下变频相位；不将其错误截断为整数中心。
- 每个BS发送一个有限包。请求码片数向上补齐到G的整数倍，保证通信符号完整；请求/实际码片数同时记录，避免截断末符号后破坏通信PSD零点。零填充长度大于两倍活动包及最大时延保护后，以有符号DFT频率实现分数时延，前端为全带矩形DFT投影。
- 这是有限离散记录上的带限插值模型，矩形脉冲先离散化，并非已验证的连续射频抗混叠实现。零填充、记录长度、Fs、前端和观测时间全部记录；后续仍需采样率/滤波敏感性。
- 传播模块读取真实物理距离产生时延、Friis幅度及RF传播相位。接收机接口不读取距离真值、用户坐标或真实信道相位；其复幅度为待估干扰参数。
- 噪声为复AWGN，采样方差 `N0*Fs`，局部RandStream固定种子，且不改变MATLAB全局随机状态。通信、其他定位分量、其他BS传播一起叠加。
- 分量名义平均功率预算与有限包实际平均功率分开保存。有限包交叉项不被强行缩放抹平。

## 码序列与已知信息

支持 `seeded_independent_bpsk` 和 `author_L1CP`。前者是可复跑的独立随机码工程模型；后者读取原目录的32×10230码表，每个同P载波的不同BS使用不同PRN，而80个跨载波分量会复用PRN。实际chips、PRN分配、种子及跨载波复用标志均保存。

作者没有给出多小区完整码分配、码相位和Omega的可复用数值，因此这些模式不声称与作者真实实现一致；q继续是独立的assumed优化门限，不能从一次捕获结果反推或校准。

接收机已知发送码、包起点时钟、BS坐标、可行区域和最大距离搜索上限；不估未知接收机钟差。传播使用已知平坦CSI假设；平均通信/定位PSD预白化需要各BS功率增益和已分配的定位功率，记录为理想CSI与网络功率知识。取得这些增益不等同于向定位求解器输入真实坐标。

## 捕获、预白化和实际测距

1. 相关器对有限接收记录与已知定位模板作FFT互相关，在来自可行区域先验的非负时延窗口内选峰。频域补零将相关序列再插值4倍后选粗峰，避免仅在整数采样延迟选峰时漏掉预白化后的窄峰；该值独立于物理采样率。
2. 在该峰附近优化带限分数时延的相关模平方，复幅度作为未知常量消除。整数时延另用直接时域移位验证，防止FFT正负号错而自洽。
3. 可选 `whitening='none'`、`known_average_C_psd` 或默认 `known_average_CP_psd`。后者用已知CSI、有限N通信PSD及其他定位分量的平均PSD构造权重，排除当前待估分量。它是高斯等效预白化，不是完整有色似然，也没有建模相干码复用产生的完整交叉协方差。保留C-only模式用于复查忽略P干扰造成的失配。
4. 有限通信PSD利用恒等式将sinc平方有限和写成正实参数trigamma尾和，避免分配N×FFT长矩阵；与直接逐载波求和独立比对。数值PSD下限仅用于白化正则化，值显式记录。
5. 检测门限由离散搜索点的AWGN并集界给出；预白化场景为高斯等效解释。在真实通信/定位干扰下未标定虚警概率；不能将detected自动解释为正确锁定。
6. 保存估计时延、`c0*delay`实际测距、边界峰、检测统计和状态。未检测不填真值；边界峰不能作为有效测距。CRB仅为局部高斯等效参考，不能当成实测误差。

## 从测距到位置及几何反馈

`geometry.estimateRanges(bsPosM,rangesM,valid,opts)`没有真实位置输入。至少三站非共线，先用距离平方差求代数初值，再用有阻尼Gauss-Newton拟合原始欧氏距离。缺站、锚点秩亏、迭代失败、残差超限和域外结果分别报告。域约束只用于验收，不把域外坐标裁剪回去。失败位置误差在汇总中保留NaN，并单独报告覆盖分母。

反馈层不改原oracle基准，另起一条实验路径：

`首次所有lambda=1 -> 带完整约束的功率求解 -> 实际采样捕获/测距/位置估计 -> 用估计位置计算几何lambda -> 再求功率`

每次功率求解内几何固定，均检查相同约束及KKT/对偶证书。反馈只更新几何，不偷偷更新为真值坐标；CSI仍按论文已知假设固定。现阶段完整更新要求所有用户位置及所有BS测距有效；任一失败则停止，保留失败轨迹，不回填oracle或只对成功用户重定义目标。

停止准则为最少fix数之后，最大估计位置变化和相对功率变化同时达标；到达fix上限单独标记，不能当成收敛。默认共同随机数使迭代间使用相同码/通信数据/噪声以分离几何作用；这不是独立时间观测的随机收敛证明，可显式关闭共同噪声。若第一轮即捕获/定位失败，尚无第二次结果可比较，位置/功率变化为NaN，反馈图对应两个子图无曲线；这表示明确停止，没有伪造零变化或漏写结果。

真实用户坐标只在传播及事后误差计算使用；报告将实测位置误差与oracle预测标准差分开。

## 输出与重放

- `sampled_ranges.csv`、`sampled_positions.csv`、`sampled_packet_audit.csv`：实际估计、失败原因、检测与包功率/时间。
- `feedback_iterations.csv`、`feedback_geometry_powers.csv`、`feedback_ranges.csv`、`feedback_positions.csv`：首次lambda、估计几何、每步功率证书及真实接收输出。
- `step_sensitivity.csv`：各倍率初始与最终接受步长、工作量、耗时、原始/对偶及KKT验收。
- `run.mat`保存实际chips、通信符号、种子、功率和完整迭代对象，避免保存大量重复FFT临时数组。manifest保存新实验状态和来源边界。

验证记录与数值见PROGRESS阶段7和STAGE7_VERIFICATION.json；新增实验不能因为成功执行就被标为作者完整CP4A或论文统计复现。17项新增检查含外部packet复用，完整回归保留原区域无C/无AWGN但仍有P干扰的失败场景，并另以中心子区域控制验证完整反馈；不能把中心区域成功替代原全区域覆盖。
