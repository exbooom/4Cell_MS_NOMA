## PCJPA 与 CP4A：早期算法补充了什么

- 早期稿算法称 PCJPA，最终版改称 CP4A。算法 1 都是外层 BS 预算价格、内层 QoS/可听价格的层次结构。
- 早期稿第 14 页给出三类约束残差作为次梯度；第 15 页算法 1 明列 `mu_next = mu - b2 * residual`、`beta_next = beta - b3 * residual`、`nu_next = nu - b1 * residual`，并含他站定位功率初始化和本轮功率更新。最终版算法更精简。
- 早期稿第 15 页正文提出首次忽略几何和多址影响后获取初值；算法表本身没有最终版的显式首次判断。最终版第 5 页正文及第 6 页算法 1 第 5-9 行明确规定首次 `lambda = 1`。
- 在所核验的算法/仿真设置及全文相关参数检索中，未找到 b1/b2/b3、iterN、epsilon 的可直接复用数值或完整步长调度。早期稿印刷更新式也未明确写出非负投影，不能把当前投影/回溯选择改标为作者原参数。
- 两稿都没有给出可直接执行的采样接收器、时延估计器、测距到位置的完整迭代实现。正文的收敛描述不替代实现与验证。

因此，当前集中式/完整对偶及两条修正候选继续保留；candidate、工程步长、固定 oracle 几何的标志不变。下一阶段仍按采样波形 -> 接收滤波/相关 -> 实际测距 -> 位置估计 -> 首次 lambda=1/几何反馈推进。
